# 有来源的旅行检索与有限修正

原生 Hermes 负责子 Agent 创建、并发、取消、进度与模型调用。旅行插件负责“当前用户需求是哪一版”“搜索额度是否耗尽”“审查引用是否来自本任务”。实现位于 [research.py](../../travel_extensions/travel/research.py)，没有新增线程池或模型 SDK。

```mermaid
flowchart LR
  U[当前人物与用户轮次] --> J[food / hotel / attraction]
  J --> N[公开原生生命周期 API]
  N --> S[仅 web_search；每方向累计 5 次]
  S --> E[记录真实返回的 URL 和摘要]
  E --> R[ctx.llm 无工具审查]
  R --> G[来源白名单与协议校验]
  G --> P[可交付候选]
  G --> F[缺口说明；最多两轮修正]
```

## 为什么需要这层业务规则

旧项目已经有来源审查、五次额度和两轮修正。本次保留这些行为与审查要求，替换外部执行器和私有模型客户端。参考旧 `review.py` 的来源编号校验，但直接接入官方 `ctx.llm.complete_structured`；调用方不再配置第二套 API 密钥。

原生模型轮次不能代替搜索额度。SQLite 条件更新负责并发计数，缓存命中与失败调用也计入；同轮同方向重试沿用额度。公共 `SubagentLaunchRequest.allowed_toolsets=("search",)` 防止偏好/方案工具被继承。`pre_tool_call` 拒绝直接绕过业务层的 `delegate_task` 和没有有效旅行子任务的搜索。

用户发来新一轮消息后旧需求过期，旧搜索被拒绝、旧结果不能交付。此规则保守：即使只说“继续”，也需要按新轮次重新发起研究；当前不声称做到了自然语言级的需求差异识别。进程重启后的原生 UNKNOWN 记录为失败，不假装恢复执行。

## 验证数据

2026-10-18：8 项业务测试通过；真实插件发现测试 1 项通过；原生委派与公开生命周期两条路径各运行三个真实子 Agent，两个用例通过（模型和搜索响应均模拟）。父 Agent 带有写工具时，公开生命周期的全部子请求仍只有 `web_search`。

- 12 个并发额度申请：只放行 5 个，第 6 次起拒绝。
- 4 类审查协议错误全部拒绝：伪造 URL、缺来源、空结果宣称完成、错误完成字段类型。
- 完全相同候选去重；别名相似实体仍依赖模型判断，不宣称自动解决全部重复景点。
- 跨会话查询、需求变化、审查期间取消、第三次之后再重试和进程重启 UNKNOWN 均覆盖。
- 重复 poll 使用已有审查结果；同一结果仅一次审查。中断在审查阶段会保留 REVIEWING，用户可显式重试，不自动重复扣费。

测试：[test_research.py](../../tests/travel_extensions/test_research.py)、[test_native_children.py](../../tests/travel_extensions/test_native_children.py)。复现使用官方 `scripts/run_tests.sh`。这些数据说明约束生效，不能证明所有旅行事实都正确。

## 质量边界

真实父子链路验收进一步固定了 hook 协议：`pre_tool_call` 用 `action: block` 拒绝调用；公开 `transform_tool_result` 收集搜索证据并返回 `None`，保持原结果不变。发布版在启动子任务时解除继承的 observer suppression，恢复子工具 `post_tool_call`，修复可选观测插件丢失完成事件的问题，详见 [观测修复](07-Langfuse.md)。未修改宿主源码。`poll` 复用原生最长 15 秒等待，减少无效模型轮询；审查结束采用带需求版本和取消条件的原子更新，阻止迟到结果写回。

目的地非空由程序检查；是否确实由用户指定、免费期限、过敏原、预算适配、实体别名由审查模型结合资料判断。摘要和来源存在不等于原网页每句话真实。最终自然语言回答仍可能遗漏引用，保存方案将直接从审查候选生成，避免再次改写丢失来源。

官方基线：[公开生命周期完整源码](https://github.com/NousResearch/hermes-agent/blob/ccc695635094d7615373db267b77f894d978b1a0/agent/subagent_lifecycle.py)、[插件模型接口](https://github.com/NousResearch/hermes-agent/blob/ccc695635094d7615373db267b77f894d978b1a0/agent/plugin_llm.py)。改进源码通过 `git diff travel-upstream-baseline-20261018 -- travel_extensions/travel` 查看。
