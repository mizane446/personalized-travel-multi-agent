## 证据与历史

- `data/showcase-*-v2.json`：当前复杂案例的真实执行与来源核对。

- `data/deepseek-*.json`、`relay-luna-failure-*.json`：历史研究，不代表当前默认模型或价格。
- 其他 `data/` 回执：安装、桌面和观测验证；真实接口与合成响应的区别见对应文档。
- `examples/旧版/`、`images/旧版/`：早期示例和被替换的图片，保留原文件用于历史引用。
